## Install

```sh
pnpm install
```

## Develop

Start the dev server in background mode:

```sh
pnpm astro dev --background
```

Then open the printed local URL. Changes to any file in `src/content/docs/` hot-reload instantly.

## Build

```sh
pnpm build
```

The static site is written to `dist/`.
